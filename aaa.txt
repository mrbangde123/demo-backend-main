  ## 二、北极星文档（原始需求）

  目标架构：
  ```
  browser → nginx → frontend → springboot-main → mysql / redis
                                      ↓
                            springboot-client-service
  ```

  **后端主服务 (demo-backend-main)**：SpringBoot + Maven + MySQL + Redis + MyBatis-Plus + RestTemplate/OpenFeign 调 client + 多环境配置
  - 功能：1 个 Controller，1 个查 DB 接口，1 个写 Redis 接口，1 个调 client 接口

  **第二个微服务 (demo-backend-client)**：简单 SpringBoot 服务，提供 HTTP 接口给主项目调用

  **前端 (demo-frontend)**：Vue 3 + Vite 简单页面调后端接口，最终也 Docker 化

  **部署要求**：GitHub 规范 / Dockerfile / docker-compose 统一拉起所有服务 / Nginx 静态资源+反代+跨域
